1.3. Программные зависимости

  • Windows: не требуется дополнительных компонентов; драйвер подписан.
  • Linux: systemd, заголовки ядра для сборки модуля (DKMS) либо готовый модуль под поддерживаемые ядра дистрибутива; ca-certificates.

2. Сервер панели управления

2.1. Операционная система

  • Astra Linux Special Edition 1.7 / 1.8, РЕД ОС 7.3 / 8, Альт Сервер 10 / 11, Ubuntu 22.04 / 24.04 LTS, Debian 12 (x86_64);
  • либо контейнерная среда: Docker 24+ / containerd, Kubernetes 1.27+.

Объём диска зависит от количества загружаемых для анализа снимков и срока их хранения (в среднем 2–5 МБ на снимок).

3. СУБД

  • PostgreSQL 14, 15, 16 или Postgres Pro Standard / Certified соответствующих версий.
  • Может быть развёрнута на сервере панели управления (входит в поставку) или на выделенном сервере СУБД заказчика.
  • Не используются СУБД Oracle, Microsoft SQL Server и иные, ограниченные к применению.

Пропускная способность: агент передаёт не более 1 КБ в минуту в штатном режиме. Доступ в Интернет не требуется ни агентам, ни серверу.

5. Рабочее место оператора панели

  • Браузер: Яндекс.Браузер 24+, Chromium / Google Chrome 120+, Mozilla Firefox 115+.
  • Разрешение экрана от 1280×720.
  • Для анализа снимков дополнительное ПО не требуется.

6. Совместимость с российским ПО

  • Операционные системы из единого реестра российского ПО: Astra Linux Special Edition, РЕД ОС, Альт (агент и сервер). Совместимость подтверждена испытаниями на актуальных версиях, указанных в п. 1.1.
  • СУБД: Postgres Pro.
  • Службы каталогов: ALD Pro, Samba DC, FreeIPA (наряду с Microsoft Active Directory).
  • Средства распространения ПО: Kaspersky Security Center, Ansible.
  • Браузер: Яндекс.Браузер.
