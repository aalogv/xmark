2. Серверная часть

Серверная часть состоит из двух ролей: сервер управления и хранения (панель, реестр рабочих станций, журналы, архив снимков) и сервер распознавания (анализ снимков). Нагрузка на первый зависит от числа рабочих станций, на второй — от числа одновременно анализируемых снимков. В небольших инсталляциях роли совмещаются на одном сервере.

2.1. Операционная система

  • Astra Linux Special Edition 1.7 / 1.8, РЕД ОС 7.3 / 8, Альт Сервер 10 / 11, Ubuntu 22.04 / 24.04 LTS, Debian 12 (x86_64);
  • либо контейнерная среда: Docker 24+ / containerd, Kubernetes 1.27+.

В объём диска входят реестр рабочих станций, журналы событий и служебные данные идентификации. Архив снимков считается отдельно: 2–5 МБ на снимок, умноженные на число анализов за срок хранения (например, 1 000 снимков в год при хранении 3 года — около 15 ГБ).

2.3. Сервер распознавания

КонфигурацияvCPUОЗУGPUДиск (SSD)
Базовая (1 одновременный анализ)48 ГБNVIDIA с поддержкой CUDA 12, от 4 ГБ видеопамяти20 ГБ
Рекомендуемая (до 4 одновременных анализов)1632 ГБNVIDIA с поддержкой CUDA 12, от 8 ГБ видеопамяти20 ГБ
Без GPU88 ГБ—20 ГБ

Время анализа — от нескольких секунд для скриншота до десятков минут для фотографии экрана под углом; без GPU анализ фотографий занимает в несколько раз больше времени. Запросы сверх числа одновременных анализов ставятся в очередь. Нагрузка на сервер распознавания не зависит от числа рабочих станций: при росте потока снимков добавляются узлы распознавания.

3. СУБД

  • PostgreSQL 14, 15, 16 или Postgres Pro Standard / Certified соответствующих версий.
  • Может быть развёрнута на сервере панели управления (входит в поставку) или на выделенном сервере СУБД заказчика.
  • Не используются СУБД Oracle, Microsoft SQL Server и иные, ограниченные к применению.

5. Рабочее место оператора панели

  • Браузер: Яндекс.Браузер 24+, Chromium / Google Chrome 120+, Mozilla Firefox 115+.
  • Разрешение экрана от 1280×720.
  • Для анализа снимков дополнительное ПО не требуется.

6. Совместимость с российским ПО

  • Операционные системы из единого реестра российского ПО: Astra Linux Special Edition, РЕД ОС, Альт (агент и сервер). Совместимость подтверждена испытаниями на актуальных версиях, указанных в п. 1.1.
  • СУБД: Postgres Pro.
  • Службы каталогов: ALD Pro, Samba DC, FreeIPA (наряду с Microsoft Active Directory).
  • Средства распространения ПО: Kaspersky Security Center, Ansible.
  • Браузер: Яндекс.Браузер.
