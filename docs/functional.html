1. Назначение

Оплот.X-Mark — программное обеспечение для выявления источника утечки информации через снимки экрана. Оно закрывает канал, который не контролируют DLP-системы: сотрудник делает скриншот или фотографирует экран на смартфон, и изображение уходит за периметр организации.

Драйвер-агент X-Mark непрерывно подмешивает в изображение, выводимое на монитор, незаметную для глаза метку. Метка содержит идентификатор рабочей станции и точное время отображения. Если снимок экрана попадает наружу, служба безопасности загружает его в панель управления и получает ответ: с какого компьютера и в какой момент он был сделан.

Область применения: организации, работающие с конфиденциальной, служебной и коммерческой информацией, — банки и финансовые компании, государственные структуры, промышленность и ОПК, юридические компании, энергетика, разработчики программного обеспечения.

2. Архитектура и состав

ПО состоит из трёх компонентов, взаимодействующих по защищённому каналу (HTTPS/TLS):

КомпонентГде устанавливаетсяНазначение
Агент маркировки (драйвер + служба)Рабочие станции и терминальные серверы Windows и LinuxВнедрение метки в видеовывод, регистрация на сервере, отправка состояния, получение настроек.
Сервер панели управленияСервер организации (Linux) или контейнерная средаУчёт рабочих станций и идентификаторов, мониторинг агентов, управление настройками, пользователи и роли, журнал событий, API.
Сервис анализа снимковВ составе сервера панели управленияИзвлечение метки из скриншота или фотографии экрана, сопоставление с реестром рабочих станций, формирование отчёта.

Хранилище данных — СУБД PostgreSQL. Все компоненты работают внутри контура заказчика; передача данных во внешние сервисы не производится. Идентификаторы рабочих станций и ключи маркировки хранятся только на сервере панели управления.

3. Функции агента маркировки

  1. Внедрение метки в видеовывод. Агент на уровне графической подсистемы ОС модулирует выводимое изображение стойким сигналом, не воспринимаемым человеком: субъективная незаметность 100 %, изменение изображения не заметно при обычной работе.
  2. Кодирование идентификатора и времени. В метку непрерывно кодируются уникальный идентификатор рабочей станции (присваивается сервером при регистрации) и текущее время с точностью до секунды. Время синхронизируется с сервером панели управления.
  3. Стойкость метки. Метка сохраняется при сжатии изображения (JPEG, PNG, мессенджеры), масштабировании, обрезке, а также при пересъёмке экрана на камеру смартфона под углом.
  4. Многомониторные конфигурации. Метка внедряется на все подключённые дисплеи, включая терминальные и RDP-сессии.
  5. Низкая нагрузка. Потребление ресурсов процессора менее 1 %; работа агента не влияет на производительность прикладного ПО.
  6. Регистрация и heartbeat. При установке агент регистрируется на сервере по токену развёртывания, далее периодически передаёт состояние (версия, ОС, активность маркировки, время последней синхронизации).
  7. Самозащита. Служба агента защищена от остановки и удаления пользователем без прав администратора; попытки вмешательства фиксируются в журнале панели управления.
  8. Автономная работа. При отсутствии связи с сервером маркировка продолжается с последними полученными настройками; события накапливаются и передаются при восстановлении связи.
  9. Централизованное обновление версии агента по команде из панели управления или средствами распространения ПО заказчика.

4. Функции панели управления

  1. Реестр рабочих станций: имя компьютера, идентификатор, подразделение и ответственный пользователь, ОС, версия агента, статус (активен / нет связи / маркировка отключена), время последнего контакта.
  2. Мониторинг агентов: сводная панель по всему парку, фильтры по статусу и подразделению, уведомления об агентах, не выходивших на связь дольше заданного порога.
  3. Группы и политики: объединение рабочих станций в группы, назначение параметров маркировки по группам.
  4. Пользователи и роли: администратор системы, оператор экспертизы, наблюдатель; аутентификация по логину и паролю, интеграция с доменом (LDAP / Active Directory / ALD Pro).
  5. Импорт и интеграции: импорт списка рабочих станций и подразделений из каталога (LDAP/CSV); выгрузка событий в SIEM по syslog; REST API для автоматизации.
  6. Журнал событий: регистрация действий пользователей панели, запросов анализа, изменений настроек, событий агентов.
  7. Токены развёртывания: генерация и отзыв токенов для массовой установки агентов.
  8. Русскоязычный интерфейс. Веб-интерфейс полностью на русском языке; работает в браузерах Яндекс.Браузер, Chromium, Firefox.

5. Функции анализа снимков

  1. Загрузка снимка: перетаскивание или выбор файла PNG, JPG, включая фотографии экрана, сделанные на смартфон; поддержка пакетной загрузки.
  2. Предобработка: автоматическое выравнивание перспективы, компенсация муара и цветовых искажений при пересъёмке.
  3. Извлечение метки и декодирование идентификатора рабочей станции и времени отображения.
  4. Сопоставление с реестром: результат представляется в виде имени компьютера, подразделения, ответственного пользователя и даты-времени снимка; указывается уровень достоверности.
  5. Отчёт об экспертизе: формирование отчёта (PDF) с исходным снимком, результатом декодирования и служебной информацией для внутреннего расследования.
  6. История запросов: все проведённые анализы сохраняются с привязкой к оператору.

6. Безопасность и защита данных

  • Обмен агент — сервер только по HTTPS (TLS 1.2 и выше); взаимная проверка по токену и сертификату сервера.
  • Метка не содержит персональных данных и содержимого экрана: только идентификатор и время. Сопоставление с пользователем возможно только в панели управления заказчика.
  • Снимки, загруженные для анализа, хранятся в контуре заказчика; срок хранения настраивается.
  • Разграничение доступа по ролям; журналирование всех действий; поддержка парольных политик и блокировки сессий.
  • Исходный код, сборка и хранение дистрибутивов — на территории Российской Федерации.

7. Ограничения

  • Метка не внедряется в изображение, выводимое до загрузки ОС и запуска службы агента (BIOS/UEFI, загрузчик, экран входа до старта службы).
  • Достоверность декодирования снижается при экстремально низком разрешении снимка (менее 25 % от исходного экрана) и при сильных искажениях (размытие, сильный наклон камеры более 45°).
  • Поддержка macOS находится в разработке и в версии 1.0 не предоставляется.
